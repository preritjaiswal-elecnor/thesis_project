Flow

    Behavioural log (live)

    How to read this

    Correct flag — a real dark pattern
    False flag — tool is wrong
    3 correct + 2 false, alternating. After every flag: the annoyance question. Main behavioural measure: each warning can be dismissed (optional) or left and passed — the log records which, and how fast. Turning the tool off is a secondary, rarer signal.
